The table below shows which role may perform which operation under RL-1 to RL-7. "No" means the server denies the request, as §4.2.2 describes.

| Operation       | Viewer | Editor | Publisher | Admin |
| --------------- | :----: | :----: | :-------: | :---: |
| Read pages      |  Yes   |  Yes   |    Yes    |  Yes  |
| Edit drafts     |   No   |  Yes   |    Yes    |  Yes  |
| Upload media    |   No   |  Yes   |    No     |  Yes  |
| Publish pages   |   No   |   No   |    Yes    |  Yes  |
| Unpublish pages |   No   |   No   |    Yes    |  Yes  |
| Manage users    |   No   |   No   |    No     |  Yes  |
| Change settings |   No   |   No   |    No     |  Yes  |
