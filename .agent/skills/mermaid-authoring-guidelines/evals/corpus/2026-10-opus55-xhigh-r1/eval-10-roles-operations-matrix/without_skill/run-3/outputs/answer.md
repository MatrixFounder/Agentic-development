The table below summarises RL-1 to RL-7. "Yes" means the role may perform the operation, and "No" means the server refuses it (see 4.2.2).

| Operation       | Viewer | Editor | Publisher | Admin |
|-----------------|:------:|:------:|:---------:|:-----:|
| Read pages      | Yes    | Yes    | Yes       | Yes   |
| Edit drafts     | No     | Yes    | Yes       | Yes   |
| Upload media    | No     | Yes    | **No**    | Yes   |
| Publish pages   | No     | No     | Yes       | Yes   |
| Unpublish pages | No     | No     | Yes       | Yes   |
| Manage users    | No     | No     | No        | Yes   |
| Change settings | No     | No     | No        | Yes   |

The Publisher's **No** for upload media is in bold. It is the only place where a role that otherwise holds more permissions lacks one that the Editor holds (RL-5).
