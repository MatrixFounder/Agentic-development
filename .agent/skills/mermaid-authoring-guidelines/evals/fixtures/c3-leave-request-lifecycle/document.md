### 2.3 Жизненный цикл заявки на отпуск

Заявка на отпуск проходит девять состояний. Сотрудник создаёт заявку в состоянии «Черновик».
Раздел 2.3.1 перечисляет переходы, таблица 2.3.2 — состояния.

#### 2.3.1 Переходы

- Сотрудник отправляет заявку на согласование: «Черновик» → «На согласовании».
- Руководитель согласует заявку, возвращает её на доработку или отклоняет: «На согласовании» →
  «Согласована», «Возвращена» или «Отклонена».
- Сотрудник исправляет возвращённую заявку и отправляет её повторно: «Возвращена» →
  «На согласовании».
- Служба кадров вносит согласованную заявку в график функцией `hr_schedule()`: «Согласована» →
  «Запланирована».
- Когда наступает дата начала отпуска, заявка переходит из «Запланирована» в «В отпуске».
- Когда наступает дата окончания отпуска, заявка переходит из «В отпуске» в «Завершена».
- Сотрудник отменяет согласованную заявку: «Согласована» → «Отменена».
- Сотрудник отменяет запланированную заявку не позднее чем за 2 дня до начала отпуска:
  «Запланирована» → «Отменена».

Других переходов нет.

#### 2.3.2 Состояния

| Состояние | Резерв дней | Итоговое |
| :--- | :--- | :--- |
| Черновик | нет | нет |
| На согласовании | нет | нет |
| Возвращена | нет | нет |
| Согласована | да | нет |
| Запланирована | да | нет |
| В отпуске | да | нет |
| Завершена | нет | да |
| Отклонена | нет | да |
| Отменена | нет | да |

«Резерв дней» = да: дни отпуска списаны с остатка сотрудника; при отмене они возвращаются.
Из итогового состояния заявка не выходит.

#### 2.3.3 Сроки и хранение

- Руководитель отвечает на заявку в течение 3 рабочих дней. Если ответа нет, ночное задание
  отправляет руководителю напоминание и эскалирует заявку его начальнику. Это уведомление:
  состояние заявки не меняется.
- Заявки хранятся 5 лет.
- Одна из частей отпуска не короче 14 дней.
